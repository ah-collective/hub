# 开源人文学者

「开源自我」即把一个人当作一份公共的文献来对待：可读、可引、并且有出处。一个人的语言的出处，是他本人的参考文献，智识上的基础源文件。这份文献只由本人写、只追加、不能回改。

我们使用最便利的基础设施解决开源自我的版本管理问题：git。每位参与者维护一个公开仓库，开源对自己最为重要的文本，并通过在不同时间重新回访同一份文本，来测量自身的智识历史。这些文本的共同特质是：定义了个人重要阶段的思想关切，且其叙述内容成为个人智识历史中某种不断被回返的母题。

这些「个人关键文献」将充当测量仪器，对个体动态的思想历史进行跨时段的测量。每次对同一文献的不同诠释，都对应一次在 git 中基于「diff」的语义运算，重读与重读之间的差异构成一次个人历史版本。

同一个人，在二〇一〇年、二〇一七年与二〇二六年，对同一段文本的理解，差异可能是显著的：

> 每位读者阅读时仅仅读到其自身。作品只是一种光学仪器，作家把它递给读者……读者在自己身上认出书里说的东西，是这本书为真的证明；反过来也至少在某种程度上成立，因为两个文本之间的差异往往不该归于作者，而该归于读者。
>
> —— Proust, *Le Temps retrouvé*

在我们即将面临的文本无限生成的时代，定稿将不再珍贵，任一人文立场都可以被无限伪造。不可伪造的，是那些真实发生过、不可回滚的个人智识历史。通过唯一的 URL，任何人或者智能体都可在未来调用一份第一人称、历时的和纵深的关键档案。
