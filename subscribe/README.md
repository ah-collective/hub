# 订阅

以月为单位一期，一期一个文件：`YYYY-MM.md`。同目录 `YYYY-MM/` 下按订阅人各一份，内容是这一期里该人订阅的那些仓的部分，贴进邮件即可。

订阅内容是仓库中出现的 diff（差异），以人为单位组织。你可以读到订阅对象在该月份个人关键文献的重读或新增；跨人的同一作品看 [catalog/](../catalog/)。

每期由脚本（`tools/monthly.py`）生成：

1. 拉取全部成员的公开仓库；
2. 取出这个月每个仓库 `key/` 下新增的条目，各配上同一作品的上一条；
3. 读每个仓库的 `pulse.md`，把成员分三类列在末尾：有条目的、报无变化的（月内追加了本月那一行）、沉默的（两者都没有）；
4. 每个仓库记一行月末的 HEAD commit hash，作为这一期的见证；
5. 顺带重建 `catalog/README.md`（文献目录）和 `fellows/<user>.md`（每人一页关键文献，开头标最近心跳）。

**每月两封邮件**：

1. **订阅**（月初）：成员按各自仓里 `subscribe.md` 的名单收上一期，作者不收自己的那份；出资人收整期。**上个月沉默的人（没条目也没心跳行）收不到这一期；哪个月恢复心跳，哪个月恢复。** 除此之外没有退出与加入的机制。
2. **心跳提醒**（月中）：正文在 [reminder.md](reminder.md)，发给全部成员，包括沉默的人。

非成员不发邮件：整期本来就公开在这里，想看的人 watch 本仓，或订各成员仓的 atom：`https://github.com/〔用户名〕/〔仓库名〕/commits/main.atom`。
