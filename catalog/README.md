## 标识体例

作品只出现在条目的 `cite:` 行，格式固定为「作者《题名》，出处，年份」。外国作者在作者后用括号给拉丁字母姓氏；题名后用括号给英译题名（原作是英文的即用原题；明确想用原语种题名时也可以，如 La biblioteca de Babel）。`id` 由脚本从 cite 生成，仿 BibTeX citekey：**作者+年份-题名**，全小写、只留字母数字。无原文使用中文转拼音。
